### Let's begin!

Look around your environment.

You may see:

- A television.
- A calculator.
- A smartphone.
- A laptop.
- A desktop computer.

These devices help us perform different activities. Some help us communicate, some help us calculate, and others help us learn.

But what exactly is a computer?

### Definition

A computer is an electronic device that receives data, processes it, produces information, and can store it for future use.

### Explanation in simple English

A computer is a machine that accepts what we give it, works on it, shows us the result, and can keep the result for later.

For example:

When you use a calculator to solve:

25 + 15

You enter the numbers. The calculator works on them and displays 40.

A computer works in a similar way, but it can perform many more activities than an ordinary calculator.

It can:

- Calculate numbers.
- Type and print documents.
- Play videos.
- Store pictures.
- Browse the internet.
- Create designs.
- Help students learn.
- Run applications and games.

### A simple way to remember

A COMPUTER RECEIVES → WORKS → SHOWS → STORES

## 1.2 Data and Information

Before understanding how computers work, we need to understand two important words: data and information.

### What is Data?

Data refers to raw facts or figures that have not yet been properly organized or processed to give meaning.

In simple English, data is information in its original form before we make sense of it.

Examples of data:

- 45
- 60
- 75
- 90

These numbers alone may not tell us what they represent.

### What is Information?

Information is data that has been processed or organized to become meaningful and useful.

For example:

A student scores:

- Mathematics: 45
- English: 60
- ICT: 75
- Basic Science: 90

When these scores are arranged into a result sheet showing the student's performance, they become useful information.

A computer works through four major stages.

These stages are called the Input, Processing, Output and Storage (IPOS) cycle.

1. Input.
2. Processing.
3. Output.

Input is the data or instruction we give to a computer.

Examples:

- Clicking a button with a mouse.
- Taking a picture with a camera.
- Speaking into a microphone.
- Touching a screen.

Processing means working on data to produce a useful result.

The computer's main processing component is called the CPU (Central Processing Unit).

### What is the CPU?

The CPU is the main component responsible for carrying out instructions and processing data in a computer.

In simple English, the CPU is like the brain of the computer. It follows instructions and performs calculations.

# HOW TO MAKE STUDENTS MASTER THIS MODULE

For the best results, do not teach this module as definitions alone.

Use this teaching approach:

1. Show before explaining. Show a real computer, keyboard, mouse, smartphone, or storage device before introducing the topic.
2. Explain in simple English. After giving a formal definition, explain it using familiar examples.
3. Ask questions during teaching. Let students answer questions before moving to the next topic.
4. Allow students to teach. Ask one student to explain a topic to another student in their own words.
5. Use pictures frequently. Show historical devices, modern computers, input devices, output devices, and computer applications.
6. Make students practise. Allow students to identify devices, use the computer, draw diagrams, and demonstrate the IPOS cycle.
7. Connect everything to daily life. Use examples from school, home, banking, communication, and business.
8. Assess understanding, not memorisation alone. A student who can explain the IPOS cycle using a real-life example understands it better than a student who only memorises the definition.
