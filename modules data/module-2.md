# MODULE 2: PARTS OF A COMPUTER

Complete Student Teaching Guide | 2 Weeks | 4 Lessons | 40 Minutes Per Lesson

This module explains the physical parts of a computer in simple English. Students will learn the names of computer hardware, what each part does, how the parts work together, and how to handle computer equipment safely.

The lessons are arranged so that students can understand the topics, answer questions during teaching, practise with real computer parts, and explain what they have learned to others.

## 1.6 System Unit

[Modern desktop computer](https://images.openai.com/static-rsc-4/T0oPdG7Sp7BSLHQGxtLj2cRMF77oVxO7z20GllQiUtqGNqCu5jB8aSxYelWICnwI9iKlGn5SjutcvQyGkAwRzx92aW6-jrgBrZFKCzyXc77dV04OcRz5c1gQ8rzSu1w8P7d0RYZPligQN1E4KTV_5hxzXPrF47Vgy9vJylvSI1u8VoPLziZPVd6lTh6t04E0?purpose=inline)

### What Is a System Unit?

The system unit is the computer case that contains important internal components such as the motherboard, CPU, RAM, and storage devices.

Simple English explanation:

The system unit is the box that contains the main parts that make the computer work.

It is sometimes called the computer case or tower.

### Important Correction

Many people call the system unit the CPU.

This is not technically correct.

- CPU means Central Processing Unit.
- System unit means the case containing the computer's internal components.

The CPU is located inside the system unit.
