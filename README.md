# Dzuel's Computer Class Curriculum

Interactive curriculum and lesson materials for Dzuel's Computer Class.

## Project Structure

- `lessons/` - Next.js (App Router) web application with interactive lessons, built with React, TypeScript, and Tailwind CSS.
- `dzuels_curriculum_1.docx` / `dzuels_curriculum_1.pdf` - Curriculum specifications and reference materials.
- `build_curriculum_1.py` - Document automation script.

## Commands

Commands run against the Next.js application in `lessons/`:

- Dev server: `npm --prefix lessons run dev` (http://localhost:3000)
- Build: `npm --prefix lessons run build`
- Production server: `npm --prefix lessons run start`
- Lint: `npm --prefix lessons run lint`
